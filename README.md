# COACHING-L シャドーイング・スタジオ

英語・中国語の原稿を端末内で取り込み、編集し、音声で練習する日本語UIのWebアプリです。英語5声・中国語3声の公開ニューラルモデルを、無料・登録不要でブラウザー内実行します。実モデルでの音声生成を確認しました。**中国語の読み変換は試験対応です。Koreとの品質比較、自然さの聴取評価、スマートフォン実機の検証は未完了です。**

## 起動

Node.js 22.12以降（この環境は24.19.0）とnpmが必要です。

```sh
cd /workspace/shadowing
ONNXRUNTIME_NODE_INSTALL_CUDA=skip npm ci --cache /workspace/.npm-cache
npm run dev
```

他のPCではチェックアウトしたディレクトリで実行し、`--cache`は省略できます。`ONNXRUNTIME_NODE_INSTALL_CUDA=skip` はブラウザー専用のアプリに不要なNode用CUDAバイナリーのダウンロードを省略する、onnxruntime-nodeの公式オプションです。TLS・チェックサムの検証は無効にしていません。

```sh
npm run build       # 型検査と静的ファイル出力（dist）
npm run preview     # ビルド版をローカルで確認
npm test           # 文分割、時刻、無音、A–B等
npm run test:e2e    # Chromium、ffmpeg、ffprobeが必要
```

ブラウザーテストはシステムの `/usr/bin/chromium` があれば使用します。ない場合は `npx playwright install chromium` で導入してください。`PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` でも指定できます。

ユーザーの許可に基づき、https://tools.coaching-l.net/shadowing/ で試験公開しています。手順は [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md) を参照してください。GitHub Pages上でも音声生成は利用端末内で動きます。課金、アカウント作成、音声APIキー登録は不要です。

## 利用の流れ

1. `.docx` / 文字情報のある `.pdf` / UTF-8の `.txt` を取り込むか、本文を貼り付けます。
2. 不要部分を編集し、必要なら「選択範囲だけ残す」「改行を整理」を使います。文の分割は全文生成の開始時に自動で行います。事前に「文に分割する」を押して確認・調整することもできます。文は直接修正、次の文と結合、任意の改行で再分割できます。
3. 選んだ言語の共通の短い試聴原稿で実在する候補を比較し、声と発話速度を確定して全文生成へ進みます。初回はモデルをダウンロードします。英語5声・中国語3声で実ブラウザー内の生成を確認済みです。中国語も同じ手順で試聴・確定・生成できます。
4. 音声がある教材では、ゲージ上のA・Bを左右にドラッグして任意の区間を指定できます。A・Bを動かすと区間リピートがオンになります。短い区間は「拡大」「区間に合わせる」で調整でき、キーボードの矢印キーや「現在位置をAに／Bに」も使えます。調整時は一時停止します。再生速度はスライダーで0.50〜2.00倍を0.05刻みで調整できます。「1.0×に戻す」で等速に戻せます。本文は「本文を見る」で開き、文を押すとそこから再生できます。持ち込み音声は代替経路として使用できますが、原稿との自動位置合わせはなく1区間として扱います。
5. リピーティングでは、文間に固定秒数または実発話時間と同じ長さ（上下限設定可能）の無音を挿入します。生成音声は再利用します。時刻を再計算するため、モード・無音を変えるとA–Bと一時録音を解除します。
6. マイク録音は明示操作で開始し、A–B区間に対応づけます。未設定なら全文です。「お手本→自分の声」で比較でき、同時再生は抑止します。
7. 無音なし全文、無音あり全文、A–B、指定文数ごとのMP3を端末内でエンコードします。分割ファイルは個別保存とZIP保存に対応します。MP3は表示上の再生速度を反映しません。
8. 「教材を保存」で原稿・文・声・生成速度・音声サンプル・練習モード・無音・A–B・回数・再生速度・リピート有効状態をIndexedDBに保存します。時刻は保存済み音声と設定から再計算します。録音の保存は任意です。保存済み教材を一覧から開き、削除できます。

## 無料条件と音声方式

詳細な根拠・声一覧・未検証事項は [docs/VOICE-RESEARCH.md](docs/VOICE-RESEARCH.md) を参照してください。

- 有料API・外部ログイン・既存Cookie・APIキーに依存しません。有料方式へのフォールバックはありません。
- ブラウザー内の公開ニューラルモデルを使い、ブラウザー標準読み上げをMP3生成の代わりに使いません。
- 試聴と本生成は同一モデル・声ID・発話速度を使用します。同一条件の試聴・文の音声は端末内でキャッシュし、ページ再読み込み後や全文生成でも再利用します。上限24件・32 MB、7日経過分は次回利用時に削除します。音声キャッシュの削除ボタンがあり、保存した教材は別に保持します。教材を削除した場合は一時キャッシュも消去します。
- 成功済みの文単位PCMは教材内に保持します。失敗文で停止し、中止・再試行でき、再試行は成功済み文を再利用します。
- モデルのトークン上限で黙って切り捨てないよう、トークナイザーの切り捨てを無効にして512トークン超を拒否します。英語エンジンで正しく読めない日中の文字は、削除せず生成エラーにします。
- 中国語はpinyin-proと公開モデルの音素表で読み変換します。第三声の変調、「一」「不」の変調、語境界を扱います。多音字・軽声・儿化が上流Misakiと完全一致するわけではありません。漢字・句読点以外の数字や英単語は、ユーザーが意図した読みへ編集します。未対応文字は削除せず停止します。
- 本文・資料・録音を外部へ送信する処理はありません。初回にHugging Face等へモデル/実行ファイルの取得通信を行います。モデルはCache Storage、教材音声はIndexedDBです。

標準の試聴は先頭1文です。長い範囲を比較する場合は試聴原稿を直接入力してください。初回のモデル取得時間は残ります。最適化と計測結果は [docs/PERFORMANCE.md](docs/PERFORMANCE.md) を参照してください。

## 上限と端末の制約

- 資料20 MB、PDF200ページ、本文50,000文字、生成1文400文字および512トークン、試聴400文字、結合音声20分。持ち込み音声50 MB・20分。
- これはサービスの無料枠ではなく、端末の負荷を抑えるアプリ側上限です。長い文は意味のまとまりでユーザーが再分割します。文の途中で自動切断しません。
- 画像PDFはOCRなし。パスワード付きPDF、旧Word `.doc`、文字化けするPDF・テキストは貼り付けを利用してください。
- モデル重みの実測容量は英語92,361,116バイト・中国語339,369,442バイトで、別に実行ファイルや声データを取得します。中国語の軽量版はWASMでNaNを出したため採用せず、通常精度版を使用します。数百MB以上のメモリーが必要で、正確なピーク使用量は未測定です。実際のファイル容量と進捗を取得中に表示します。スマートフォンでの実行速度・メモリー・品質は未確認です。
- 最新Chrome/Edgeを検証対象にしています。開発環境ではLinux Chromiumで機能を確認しました。Safari/Firefox、iOS/Android実機での音声生成・録音・ダウンロードは未確認です。
- 録音にはHTTPSまたはlocalhostとマイク権限が必要です。拒否時も通常再生は利用できます。
- 再生速度はHTMLMediaElement.preservesPitchを使います。A–Bの末尾監視はrequestAnimationFrameとtimeupdateで、数十ms程度のずれがあり得ます。背景・画面ロック時は精度を保てないため再生を停止します。
- モバイルでは最初の再生やモデル取得後の再生に再タップが必要になることがあります。ZIP保存が難しい場合は個別のMP3保存を使ってください。
- MP3は圧縮形式のためエンコーダー遅延・末尾パディングを含みます。元のPCMの語尾はすべて入力します。A–Bだけは指定したサンプル範囲で切り出します。
- プライベートブラウズやサイトデータ削除、容量圧迫で保存が消える場合があります。音声ファイルを別途保存してください。クラウド同期・教材全体のバックアップは未実装です。
- まだサービスワーカーは導入していません。モデルがキャッシュ済みでも、アプリそのもののオフライン起動を保証しません。

## 構成

- `src/documents.ts`: 文書抽出（Mammoth / PDF.js）。
- `src/core.ts`: 文分割、無音、タイムライン、PCM結合、WAV。
- `src/engine.ts`, `engine.worker.ts`: 交換可能な音声エンジン境界とブラウザー内推論。
- `src/Practice.tsx`: 再生、A–B、録音比較、出力画面。
- `src/Timeline.tsx`, `src/range.ts`: 波形ゲージ、A–Bドラッグ・拡大、区間境界の検証。
- `src/export.ts`, `mp3.worker.ts`: MP3のワーカーエンコードとZIP。
- `src/storage.ts`: IndexedDBの教材保存。音声をlocalStorageへ入れません。
