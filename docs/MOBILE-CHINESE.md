# iPhone・iPadの中国語音声

iPhone・iPadでの中国語の試聴・声の確定・全文生成を従来どおり有効にしました。先の中国語制限は、利用者が報告した英語MP3の文字起こしの問題を、中国語の音声生成の問題と取り違えたために追加したものでした。中国語の音声生成モデル・声データ・読み変換は変更していません。

中国語は従来のKokoro v1.1-zh FP32モデルを使用します。以前調査したfp16・q4f16・signed int8への変更は採用していません。iPhoneで利用できないと一律に判定する処理や、PCで作成することを必須にする案内を削除しました。今回の英語文字起こしの修正は[MOBILE-ASR.md](MOBILE-ASR.md)を参照してください。

音声取り込み時の言語保持、言語変更で取り込み音声を失わない修正、言語切り替え時のWorker解放は維持します。生成の途中終了を検出する記録は作業ID・言語・開始時刻・処理段階・試聴/全文の種別だけで、原稿・教材名・ファイル名・音声は含みません。手動の再読み込みでも残り得るため、クラッシュ原因の断定には使いません。原稿の自動保存・生成の自動再開は行いません。

iPhoneのUser-Agentを指定したChromiumと制御したWorkerで、中国語の試聴・全文生成を再び開始できること、英語への切り替えと音声取り込み・再生・A–B・速度変更が利用できることを確認しました。iPhone実機やSafariエンジンでの再検証ではありません。
