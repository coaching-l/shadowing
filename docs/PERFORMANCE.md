# 待ち時間の改善

## 行った変更

- 再生速度をaudio-loop-playerと同じスライダーに変更。0.50〜2.00倍・0.05刻み、現在値表示、1.0倍に戻す操作に対応。音声生成時の発話速度は別設定。
- 試聴の標準原稿を先頭2文から1文へ変更。文の途中では切らず、本文は変更しない。ユーザーが試聴原稿を入力すれば、その全文を使う。
- 同じ声・原稿・生成速度の音声をIndexedDBで再利用。ページ再読み込み後の試聴、試聴と同じ文の全文生成、保存済み教材にある文の試聴で再生成を省く。
- 音声キャッシュは最大24件・音声32 MB、メモリーは8件・8 MB。7日を超えたものはアプリの次回利用時に削除。キャッシュは任意の最適化で、保存拒否や容量不足時も通常の音声生成へ進む。
- 永続キャッシュのキーは原稿・声・速度・モデル版を含むキーのSHA-256。キャッシュDBに原稿の文字列は重複保存しない。音声には本文の読みが含まれるため、端末内への一時保存を画面で説明し、削除ボタンを用意。教材の削除時も一時キャッシュを消去する。
- PDF/Wordの公開読み込みコードをファイル選択中に先読み。PDFの読み取りWorkerを再利用し、最大4ページを並行抽出。結果はページ番号の順に結合する。Wordは読み込みコード取得とファイル読み取りを並行する。PDFの処理ページ数を表示。

## 計測

2026-10-25、Linux Chromium、同じ環境からテスト用の40ページPDFと一般的な短い英文を使用。ファイルの本文・原稿・音声は外部サーバーに送らず、ネットワークはGETに限定した。

| 操作                           |       旧公開版 | 新しい本番ビルドのローカルプレビュー |
| ------------------------------ | -------------: | -----------------------------------: |
| 40ページPDF・初回              |       1,678 ms |                               701 ms |
| PDF読み取り処理を再利用        |         未計測 |                                81 ms |
| 標準試聴・初回準備と生成       | 46,540 ms・2文 |                       20,790 ms・1文 |
| 同じページ内で同じ試聴を再利用 |         317 ms |                               290 ms |
| ページ再読み込み後の同じ試聴   |         未計測 |                               108 ms |

旧版は公開サイト、新版はローカルの本番プレビューを開いているため、アプリ本体の通信条件が異なる。単発の測定で、ネットワーク・CPU負荷・試聴原稿の長さの影響も含む。モデルの推論そのものがこの比率で高速化した、あるいは全端末で同じ秒数になるとは扱わない。

試聴原稿は `What would you like to focus on today? Take a moment to reflect on your progress.`。旧版の音声長は4.625秒、新版の標準試聴は先頭1文の2.325秒。再読み込み後の試聴ではモデルへの追加リクエストが0件で、保存済み音声が使われたことを確認した。

## 残る制約

初回のモデルダウンロードと、初めて読む原稿・声の推論時間は残る。英語約92 MB、中国語約339 MBのモデルは変更しておらず、検証済み音声エンジン・精度を落とす方法や、有料APIへ切り替える方法は採用していない。スマートフォン実機の速度、重い画像・フォントを含むPDFや大きなWordの速度は個別の検証が必要。

## 公開サイトでの最終確認

同じテストを新しい公開版（アプリソース4206705）で実施した結果：40ページPDFは初回1,172 ms、次のPDFは138 ms、標準1文の初回試聴は31,575 ms、同一ページ内の再利用は165 ms、ページ再読み込み後は151 ms。再読み込み後のモデルへの追加リクエストは0件でした。同じ1文を全文生成に使った場合は250 msで、モデルへのリクエストは0件。0.05刻みのネイティブ速度スライダーで1.05倍を指定し、HTMLAudioElementのplaybackRate=1.05とpreservesPitch=trueを確認しました。

これも単発の測定です。初回試聴は旧版と比べて原稿が2文から1文に短くなっており、エンジン単体の速度比較ではありません。再利用された音声は同一モデル・声・生成速度のPCMです。
